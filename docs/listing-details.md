# 업체 상세와 조건별 참고 견적

`GET /api/v1/directory/{listingId}`는 공개 중이며 지점·기관이 활성 상태인 업체의 승인된 정보만 반환한다. 존재하지 않는 ID, 초안 ID, 게시 중단·휴업 업체는 404이다. 목록은 가벼운 기본 정보만, 상세는 사진·주차·견적을 제공한다. DB 장애는 오류로 응답한다.

## 저장과 검수

- 초안 `CatalogData.details`: 소개, 주차, 사진 최대 12장, 참고 견적 최대 24건. 기존 8열 CSV는 기본 정보 등록용으로 유지한다. 기존 JSON에서 details가 없으면 빈 목록/미확인으로 읽는다.
- 공개 검수 시 최근 90일 이내 정보 확인과 사진 사용 권한을 검증한다. 견적은 개별 출처·확인일을 가진다.
- `ops.catalog_publication.approved_data`와 `catalog.listing_fact`가 검수 버전을 보존한다. V905의 `catalog.listing_detail`, `catalog.reference_photo`, `catalog.reference_quote`에 조회용 정형 데이터를 같은 트랜잭션으로 기록한다. 주차 대수는 `partner.branch`에도 반영한다.
- 초안 수정만으로 공개 내용이 바뀌지 않는다. 재게시 시 상세 데이터 전체 교체, 버전 충돌 시 409, 제약 조건 오류 시 공개 작업 전체 롤백. 중단 후에도 검수 이력은 보존하되 공개 상세는 차단한다.
- 현재 공개 API는 승인 스냅샷을 읽는다. 정형 테이블은 미래 업체 간 조건 검색의 기반이며 직접 쓰는 별도 관리 경로는 제공하지 않는다.

## 사진

파일 업로드 대신 권한이 확인된 **외부 HTTPS 이미지 주소**와 설명·제공자·출처·권한 근거를 등록한다. 서버는 외부 URL을 가져오거나 DNS 조회하지 않는다. IP 리터럴·내부용 호스트 표기·인증정보·비표준 포트·HTTP/data/javascript 주소를 거절한다. 브라우저가 외부 이미지 호스트에 직접 연결하므로 운영자는 신뢰할 수 있는 제공자의 주소를 사용해야 한다. URL 문법 검사는 DNS 재지정까지 막는 호스트 허용 목록이 아니다.

이미지는 참조 페이지 주소를 전달하지 않고 지연 로딩한다. 실패하면 대체 안내를 표시한다. 영구 보관, 이미지 파일 검사·변환, 업로드·오브젝트 저장소 연동은 후속 기능이다. 사진 사용 허락 확인은 URL 검증과 별개로 관리자가 수행한다.

## 주차

가능 대수, 무료 시간(분), 요금·주차권 조건, 발렛 제공 여부, 진입·대체 주차, 셔틀·교통 안내를 구분한다. 숫자/불리언의 NULL은 미확인이다. 0대/0분/false와 다르다. 대수는 남은 공간 또는 예약 보장이 아니다.

## 참고 견적

정확한 적용 날짜·한국 시간 시작 시각·예상 인원·최소 보증 인원·금액(KRW 정수)·부가세 상태·포함/제외 항목·추가 조건·출처·확인일·유효 기한을 기록한다. 예식장은 예상/보증 인원이 필수다. 요일은 날짜에서 계산하므로 별도 저장 값과 어긋나지 않는다.

사용자는 상세에서 날짜/요일/시각/예상 인원을 필터링한다. 일치한 등록 사례만 보여주며 다른 조건의 가격을 환산하지 않는다. 지난 일정·유효 기한 경과·확인 후 90일 경과를 표시한다. VAT 별도/미확인 가격은 최종 총액으로 표시하지 않는다.

참고 견적은 실제 가격표 기반 계산, 공휴일/성수기 규칙, 예약 가능 슬롯, 사용자 조합 견적 저장을 구현한 것이 아니다. 그 기능은 기존 `pricing.offer_revision/charge_rule/estimate`와 `planning.*`의 별도 업무 흐름으로 연결해야 한다. 견적 사례를 가격 규칙으로 암묵 변환하지 않는다.

## 검증

실제 PostgreSQL CI에서 V905, 상세/사진/견적 저장과 읽기, 초안과 공개 버전 격리, 재게시 교체, 게시 중단/휴업 시 404, 제약 위반의 전체 롤백을 검사한다. API 테스트는 관리자/CSRF, 음수 금액, 사진 권한, URL·인원·시각·신선도 검증과 기존 스냅샷 호환을 검사한다. 브라우저 테스트 fixture는 운영 업체 데이터로 게시하지 않는다.
