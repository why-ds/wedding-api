# 업종별 가상 데이터

`/preview/catalog`에서 10개 업종별 2개, 총 20개 샘플을 조회한다. 각각 사진 영역용 자체 SVG 일러스트 1개, 주차 정보, 토요일 2027-02-27 12:00 / 일요일 2027-02-28 18:00의 가상 견적 2개를 가진다. 총 40개 견적이며 실제 판매 조건이나 예약 가능 시간을 뜻하지 않는다.

- V906: `search.demo_catalog_entry` 전용 테이블. V907(`db/demo`): 고정 ID의 샘플 seed. Flyway 이력으로 재배포 시 중복 삽입되지 않는다.
- 실제 기관·업체·검수 자료·가격표 테이블에는 더미를 삽입하지 않는다. 기존 실제 업체 목록, 찜, 관리자 초안/게시 흐름과 분리한다. 샘플은 관리자 편집/게시 대상이 아니다.
- 읽기 전용 API: `GET /api/v1/demo/directory?category=&query=&page=0`, `GET /api/v1/demo/directory/{id}`. 모든 응답은 `demo:true`, 목록은 20개/페이지와 제한된 조건을 사용한다.
- PostgreSQL 프로필은 DB를 조회한다. DB 장애를 파일/메모리 fixture로 대체하지 않는다. 로컬 `demo` 프로필은 저장소 없는 빈 목록과 `persistent:false`를 명시한다.
- 샘플에 실제 연락처·정확한 주소·업체 출처·리뷰를 만들어 넣지 않는다. 이미지도 실제 업체 사진으로 오인하지 않도록 일러스트에 문구를 내장하고 화면 전체에 가상 표시한다. 외부 이미지 요청은 없다.
- 메이크업 혼주 인원, 촬영 시간·인원·원본/수정본, 드레스 대여 구성, 예물 소재, 예복 맞춤, 영상 촬영/납품 해상도 등은 설명·포함/제외 항목의 예시다. 카테고리별 구조화된 옵션 편집과 범용 가격 엔진의 구현을 뜻하지 않는다.
- 관리자에서는 하단의 더미 데이터 링크로 확인한다. 검수해 실제 업체로 전환하는 버튼은 제공하지 않는다.

PostgreSQL CI는 전체 20개/업종별 2개/견적 2개, DB 검색·상세 조회, 실제 상세 404, 찜 거절, 초안 비혼입을 검사한다. 체험 fixture 출처 날짜 2026-09-28은 실제 검수일이 아니다.
