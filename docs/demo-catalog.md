# 업종별 가상 데이터

`/preview/catalog`에서 10개 업종별 2개, 총 20개 샘플을 조회한다. 각 샘플에 자체 SVG 일러스트가 있으며, 18개에는 토요일/일요일 가상 견적 2개씩(36개)이 있다. 아이폰스냅·본식스냅 샘플 A는 사용자 제공 자료의 참고 상품 5개로 대체했으며, 자료에 없는 임의 일정 견적과 주차 정보는 제거했다. 어느 샘플도 실제 판매 조건이나 예약 가능 시간을 뜻하지 않는다.

- V906: `search.demo_catalog_entry` 전용 테이블. V907(`db/demo`): 고정 ID의 샘플 seed. Flyway 이력으로 재배포 시 중복 삽입되지 않는다.
- 실제 기관·업체·검수 자료·가격표 테이블에는 더미를 삽입하지 않는다. 기존 실제 업체 목록, 찜, 관리자 초안/게시 흐름과 분리한다. 샘플은 관리자 편집/게시 대상이 아니다.
- 읽기 전용 API: `GET /api/v1/demo/directory?category=&query=&page=0`, `GET /api/v1/demo/directory/{id}`. 모든 응답은 `demo:true`, 목록은 20개/페이지와 제한된 조건을 사용한다.
- PostgreSQL 프로필은 DB를 조회한다. DB 장애를 파일/메모리 fixture로 대체하지 않는다. 로컬 `demo` 프로필은 저장소 없는 빈 목록과 `persistent:false`를 명시한다.
- 샘플에 실제 연락처·정확한 주소·업체 출처·리뷰를 만들어 넣지 않는다. 이미지도 실제 업체 사진으로 오인하지 않도록 일러스트에 문구를 내장하고 화면 전체에 가상 표시한다. 외부 이미지 요청은 없다.
- 메이크업 혼주 인원, 촬영 시간·인원·원본/수정본, 드레스 대여 구성, 예물 소재, 예복 맞춤, 영상 촬영/납품 해상도 등은 설명·포함/제외 항목의 예시다. 카테고리별 구조화된 옵션 편집과 범용 가격 엔진의 구현을 뜻하지 않는다.
- 관리자에서는 하단의 더미 데이터 링크로 확인한다. 검수해 실제 업체로 전환하는 버튼은 제공하지 않는다.

PostgreSQL CI는 전체 20개/업종별 2개, DB 검색·상세·상품 조회, 실제 상세 404, 찜 거절, 초안 비혼입을 검사한다. 체험 fixture 출처 날짜 2026-09-28은 실제 검수일이 아니다.

## 사용자 제공 상품 자료 (V908/V909)

- `search.demo_product_sheet`에 상품·추가 옵션·출처 설명을 별도로 저장한다. V908은 테이블, V909는 `db/demo`의 참고 자료 seed와 기존 샘플 2개 수정이다. 적용된 V907을 변경하지 않는다.
- 아이폰스냅 샘플 A (`...0091`): BASIC 38만원 / SIGNATURE 45만원 / HIGH-END 53만원, VAT 포함. 이전 취소선 금액은 현재 할인으로 보증하지 않는다. 사진/짧은 영상 수량은 합계다.
- 본식스냅 샘플 A (`...0081`): 60p 130만원 / 80p 150만원. 사용자 표현은 DVD였지만 자료는 앨범/JPG이므로 사진 카테고리로 분류한다. VAT·출장비·납기는 미확인이다.
- 원본 포스터를 재게시하지 않는다. 제공 자료의 URL·게시일·최신성·유효 일정은 미확인이고, 등록 기준일을 가격 검증일로 사용하지 않는다. 실명 연락처나 리뷰를 추가하지 않는다.
- `GET /api/v1/demo/directory/{id}/product-estimate?productId=...&option=...&hours=1&extensionOperators=1&travel=UNKNOWN`은 DB 가격으로 서버에서 계산한다. 임의 가격 입력은 받지 않는다. 지정 1개, 중복/미등록/다른 상품 옵션 거절, 옵션 최대 12개, 연장 1~12시간·실제 선택 촬영 인원 이하 최대 3명을 검증한다. 12시간 상한은 시스템 입력 제한이며 업체가 12시간까지 제공함을 뜻하지 않는다.
- 대표/부대표 지정은 촬영 인원을 2인으로 대체한다. 추가 작가 비용을 자동 부과하지 않는다. 명시적 작가 추가 선택만 40만원을 더한다. 연장은 30만원 × 선택 시간 × 실제 연장할 인원이다.
- 본식 추가 옵션의 동시 적용 가능 여부는 자료의 “택 1” 표현 때문에 미확인이다. 화면은 조합을 비교하는 참고 계산이고 계약 가능 조합으로 보증하지 않는다.
- 출장비 미확인 시 소계만 표시한다. 아이폰 출장비 적용을 선택하면 2~5만원 범위를 별도 계산한다. 출장비 없음은 사용자 가정이고 지역명으로 자동 추정하지 않는다. 세금 미확인 시 임의 10%를 더하지 않는다.
- API 장애 시 이전 조건의 금액을 남기거나 브라우저에서 대체 계산하지 않는다. 샘플을 실제 관리자 상품으로 게시하거나 마이페이지에 계약 견적으로 저장하는 기능은 이 변경의 범위에 없다. 향후 실제 가격표는 검수·버전·유효 기간·승인된 옵션 규칙을 갖춘 별도 도메인으로 구현해야 한다.
